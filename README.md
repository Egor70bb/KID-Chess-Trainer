# KID — King's Indian Defence Trainer

Allenatore interattivo gratuito per studiare posizioni tipiche della Difesa Est-Indiana dopo la 10ª–15ª mossa del Bianco.

## Funzioni

- nuova posizione casuale;
- scacchiera orientata dal lato del Nero;
- risposta in notazione algebrica;
- punteggio sintetico da 1 a 10;
- motivazione strategica e mossa principale;
- nessun account, database o servizio a pagamento.

## Pubblicazione

Il progetto è composto solo da HTML, CSS e JavaScript ed è pronto per GitHub Pages.
